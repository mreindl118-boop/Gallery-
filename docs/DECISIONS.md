# Decisions

Choices the brief left open, with the reason. Newest last.

| Date       | Decision                                                                                                                                                                                           | Reason                                                                                                                                                                 |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-09-30 | Electron 44, electron-vite 5, Vite 7, React 19.3, zod 4, TypeScript 5.9                                                                                                                            | Current stable at start. electron-vite 5 supports Vite ≤ 7, so Vite 8 waits.                                                                                           |
| 2026-09-30 | Engine is a second entry of the main build (`out/main/engine.js`), forked with `utilityProcess.fork`                                                                                               | Shares the main build's externals and aliases; one output folder to package.                                                                                           |
| 2026-09-30 | One IPC channel (`gallery:rpc`) with a method name, instead of one channel per method                                                                                                              | The contract lives in one zod table; main validates sender and input in one place.                                                                                     |
| 2026-09-30 | RPC errors travel as `{ ok: false, error: { code, message } }` values                                                                                                                              | Electron strips custom properties from thrown errors across `invoke`.                                                                                                  |
| 2026-09-30 | Renderer ↔ main requests go through main even for engine methods; engine → renderer events go straight over a MessagePort                                                                          | Main stays the single trust boundary for requests; high-volume events skip main entirely.                                                                              |
| 2026-09-30 | Project folder names: forbidden characters become spaces, trailing dots/spaces trimmed, reserved device names get " project", max 80 characters, collisions numbered " 2", " 3" case-insensitively | Windows/NTFS rules; readable names in Explorer; the display name in project.json keeps the user's exact text.                                                          |
| 2026-09-30 | New projects are created immediately as "Untitled project" with the title in edit mode                                                                                                             | Fewer steps than a dialog; the folder exists at once so imports can start.                                                                                             |
| 2026-09-30 | New projects go first in the Library order; projects found by a rescan are appended by creation date                                                                                               | The newest work is what the user is about to use.                                                                                                                      |
| 2026-09-30 | A copied project folder inside the same Library gets a fresh id (the folder the registry knew keeps the original)                                                                                  | Ids must be unique per Library; copying to another PC keeps the id.                                                                                                    |
| 2026-09-30 | project.json files with a newer schema are skipped, never rewritten                                                                                                                                | Never damage data written by a newer app version.                                                                                                                      |
| 2026-09-30 | App settings (Library path, theme, units, centerline) live in `userData/settings.json`                                                                                                             | They are per machine, not per Library or project.                                                                                                                      |
| 2026-09-30 | Library folder watcher: non-recursive `fs.watch` on the Library root, 400 ms debounce, then rescan                                                                                                 | Cheap, and catches renames/deletes made in Explorer. chokidar is reserved for the M8 source folder.                                                                    |
| 2026-09-30 | Empty projects show an empty plinth with the dashed outline of their site                                                                                                                          | The Library's idea is "every project is an architectural model"; before a gallery exists, its site is honest.                                                          |
| 2026-09-30 | The Library page has a "Library" heading in Newsreader 36                                                                                                                                          | Anchors the grid; the wireframe left room for it.                                                                                                                      |
| 2026-09-30 | Delete asks for confirmation even though it goes to the Recycle Bin                                                                                                                                | Deleting a project with tens of thousands of photos is heavy to restore; one confirmation is cheap.                                                                    |
| 2026-09-30 | Darkroom accent is a lighter cutting-mat green (#7FBFA6)                                                                                                                                           | #2F6B57 fails 4.5:1 on #262626; the lighter tone keeps the hue and passes.                                                                                             |
| 2026-09-30 | Renderer-only packages are devDependencies                                                                                                                                                         | Vite bundles them into the renderer; the packaged app ships only what main/engine require.                                                                             |
| 2026-09-30 | Windows installer verified on a GitHub Actions windows-latest runner (build, silent install, launch; portable launch)                                                                              | The development container can cross-build the portable exe but NSIS needs 32-bit Wine.                                                                                 |
| 2026-09-30 | Test hooks are environment variables (`GALLERYLAB_USER_DATA`, `GALLERYLAB_DEFAULT_LIBRARY`, `GALLERYLAB_HIDDEN`)                                                                                   | Lets e2e and CI run isolated without adding test-only UI.                                                                                                              |
| 2026-09-30 | Releases are built and published by `.github/workflows/release.yml` on a Windows runner (tag push `v*.*.*` or manual dispatch with a version), never from a developer machine                      | Every download is built from a committed sha, checked (typecheck, lint, tests), smoke-tested installed and portable, and published with SHA-256 checksums.             |
| 2026-09-30 | Release assets are only the setup exe, the portable exe and `SHA256SUMS.txt`; no `latest.yml`/blockmaps                                                                                            | There is no auto-updater yet; shipping update metadata would imply one.                                                                                                |
| 2026-09-30 | v0.1.0 ships unsigned, as a regular (not pre-) release; versions with a `-suffix` publish as pre-releases                                                                                          | No code-signing certificate yet; release notes explain the SmartScreen prompt. 0.x already signals early software, and a regular release makes `releases/latest` work. |
| 2026-09-30 | Release notes live in `.github/release-notes/v<version>.md` and the release job refuses to run without them                                                                                        | Notes are reviewed in the same commit as the code they describe.                                                                                                       |
